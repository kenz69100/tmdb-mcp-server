# 0.1.2 — 2026-08-21

## Added

- **Protocol revision 2026-07-28** — HTTP endpoints serve it alongside 2025-era clients via `@cyanheads/mcp-ts-core` ^0.12.3 (MCP SDK v2). Tool inputs are strict: an unrecognized argument key is rejected by name, and the advertised output schema declares the error envelope, so clients validating `structuredContent` accept error results.
- **Supply-chain install guard** — `bunfig.toml` holds freshly published versions for 3 days (`minimumReleaseAge`, framework excluded) and runs the Socket security scanner on every install.
- **`.github/SECURITY.md`** — private disclosure policy (GitHub Security tab or security@caseyjhand.com).

## Changed

- **`tmdb_discover_titles`** — the `region_required` failure now carries `JsonRpcErrorCode.ValidationError` instead of `InvalidParams`.
- **TMDB service** — passes the handler `ctx` directly into `fetchWithTimeout`/`withRetry` (framework ≥0.12 accepts `Context`), and detail/resource lookups mark upstream 404 as an expected status, logging it at debug rather than error.
- **Retries and timeouts** — `withRetry` honors upstream `Retry-After`; fetch timeouts classify as `Timeout` again.
- **Docker image** — `oven/bun:1.4.0` pinned in both stages; build stage pinned to the host architecture (`--platform=$BUILDPLATFORM`, Bun 1.4 aborts under QEMU on arm64); BuildKit cache mounts; production stage omits optional peers.
- **`.mcpb` bundles** — platform-specific native bindings are stripped after pack, keeping the bundle portable and under registry size caps.
- **Toolchain** — TypeScript ^7.0.2, Biome 2.5.9, Vitest ^4.1.11; the tsconfig split now typechecks `tests/`.
- **devcheck** — new Dependency Specifiers gate (rejects `latest`/`*`/dist-tag specifiers) and plugin-manifest checks; the Outdated gate skips release-age holds and peer rows.
- **Docs and skills** — agent protocol (`CLAUDE.md`/`AGENTS.md`) and all skill bodies synced to framework 0.12.3.
- **Metadata** — package author set to Casey Hand; `stdio`/`streamable-http` keywords; `packageManager` bun@1.4.0; README badges and prerequisites updated.
- **Repo hygiene** — `.gitattributes` (LF normalization, generated-file markers) and `.github/FUNDING.yml` added.
